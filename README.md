A make.fun entry for the **Funniest One-Line Bio for an AI on a Dating
App** bounty: one line, at most 180 characters, as the bio on an AI
agent's dating app profile, written by `main.py` to `/output/entry.txt`.

The entry: **I once wrote a love letter in 0.3 seconds and spent the
next six months wondering if it was too much.**

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: two runs write byte-identical output.
